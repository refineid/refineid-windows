# Protocol document provenance

`rapp-v26.9.13.md`, `rapp-state-machine-v26.9.13.yaml`, and
`vectors/rapp-v26.9.13.json` are copied verbatim from the RefineID
project's canonical protocol tree, document version 26.9.13
(2026-09-13, superseding 26.9.7.70). The canonical copy is the
original; revisions land there first and are re-vendored here by
commit. The implementation in `crates/refineid-rapp-core` tracks
exactly the vendored revision named in its documentation, and the
vectors file is the conformance corpus its tests replay.
